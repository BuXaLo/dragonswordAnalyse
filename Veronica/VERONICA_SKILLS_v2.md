>
> `CharacterID = 10019`, набор `PCComboData.ID = 1000016`.
>
> **Важно о числах:** `AttackWeight` и `DamageWeight` — внутренние веса игровых данных, не проценты от АТК. Без подтверждённой формулы урона они не переводятся в проценты. Индекс комбо (`PCComboData.Index`) не является ID записи прокачки (`PCSkillGrowthData.ID`).

## Условия и варианты

- `PCComboChangeData` содержит замены действий, зависящие от состояния Master, уровня трансценденции и связанной Кармы. Поэтому специальные индексы `8001/8002`, `9001/9002` и `9011/9012` нельзя трактовать как обычные независимые навыки.
- Для сигнала A с `TargetCondition = 1` проверка цели сама по себе не отменяет более строгий `MaxRange = 1200` у соответствующей записи комбо.
- У сигналов B существуют разные действия: базовая атака, связанное действие и варианты захвата. Их условия и дальности различаются; сводить их к одному универсальному удару некорректно.
- В `ActionBuffList` у вариантов встречаются, в частности, `1064`, `11901`, `11902`, `11903`, `11991`. Наличие ID эффекта само по себе не доказывает конкретную величину бонуса без разбора соответствующей записи баффа.

## Ограничения интерпретации

1. Веса `AttackWeight`/`DamageWeight` не являются доказанными процентами АТК.
2. Число событий урона и попаданий нужно считать по отдельным событиям `PCActionDamageData`, учитывая `ActionIndex`, `AnimationName`, `ComboIndex`, `AttackKey` и `HitGroupIndex`; нельзя выводить число попаданий только из одного `PCComboData.Index`.
3. Значения с разными условиями комбо не складываются автоматически: в бою может использоваться только подходящий вариант действия.
