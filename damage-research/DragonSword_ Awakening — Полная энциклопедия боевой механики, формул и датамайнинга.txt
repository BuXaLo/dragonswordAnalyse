DragonSword: Awakening — Полная энциклопедия боевой механики, формул и датамайнинга (Генеральный документ)
________________
Статус документа: Это единственный актуальный генеральный справочник по боевой системе и формулам игры. Документ аккумулирует все результаты исследований: эмпирические внутриигровые тесты (Эйлин, Дана, Ария, Калиен), датамайнинг серверных XML-таблиц (MesmerizedData, MonsterStatData, StatDefaultData, BattleAdjustData, GameBuffData, PCActionDamageData, MonsterActionDamageData), реверс-инжиниринг через Cheat Engine (VEH Debugger) и статический анализ C++ кода в Ghidra (DSClient-Win64-Shipping.exe).
1. Итоговая генеральная формула урона
________________
FinalDamage = CalcBaseDamage × Attacker_DamageWeight × (1 - calc_damage_reduce) × Crit × BreakMultiplier × CalcMesmerizedDamage × (1.0 + ElemReaction%)
* CalcBaseDamage (Базовый урон удара): Total_ATK × Skill% — произведение суммарной атаки персонажа на номинальный процент умения.
* Attacker_DamageWeight (Вес конкретной тычки): Доля урона внутри анимации комбо (извлечена из структуры OffenceParameter в PCActionDamageData). Сумма всех тычек серии равна проценту из карточки навыка (например, комбо Даны на 394% разбито на веса 0.075, 0.234 и финал). Одиночные удары (бомба Арии) имеют вес ровно 1.0.
* calc_damage_reduce (Поглощение броней цели):
Множитель прохождения = K / (DEFeff + K)
где DEFeff = (BaseDEF × (1 - DefIgnore%)) - FlatPen
Точная константа из бинарного кода: K = 1200.0f (Hex: 0x44960000). Для манекена тренировочного огра подтверждена базовая защита: BaseDEF = 1200.0f.
* Crit (Критический урон): Строго аддитивный множитель: 1 + (CritDMG% / 100) (+75% дает ровно ×1.75; +117.28% дает ровно ×2.1728).
* BreakMultiplier (Множитель пробитого суперармора): Включается при разбитии шкалы стойкости (Break/Groggy): 1.0 + (Break_Damage_Per - Break_DamageResist_Per) / 100 (базово в движке дает ×1.2–1.5 чистого урона).
* CalcMesmerizedDamage (Множитель жесткого контроля): По целям в состояниях DOWN, STUN, AIR, HOLD или FREEZE множитель равен ×2.0 (+100% чистого урона).
* ElemReaction% (Элементальные комбо): Уязвимости при атаке нужной стихией по статусу: Огонь по Яду (+50%), Шок по Воде (+100% / ×2.0), Шок по Холоду (+50%), Яд по Шоку (+50%).
2. Подтвержденные машинные формулы характеристик (Ghidra, функция FUN_1464cf980)
________________
В ходе реверса исполняемого файла игры (точка входа найдена через перехват инструкции записи movss [rcx+0C], xmm6 по смещению +64C0AD4) вскрыта функция обновления характеристик FUN_1464cf980. Все боевые параметры подчиняются единому закону:
Итоговый параметр = (1.0 + Бонус%_A + Бонус%_B) × (Базовое_значение + Плоские_прибавки)
   * Атака (ID: 1 плоская, ID: 7 процентная): Total_ATK = (1.0 + ATK%) × (Base_ATK + Flat_ATK)
   * Защита (ID: 2 плоская, ID: 8 процентная): Total_DEF = (1.0 + DEF%) × (Base_DEF + Flat_DEF)
   * Здоровье (ID: 3 плоское, ID: 9 процентное, ID: 13 текущее HP): Движок считывает коэффициент заполнения полоски Ratio = Current_HP / Old_Max_HP, пересчитывает новый максимум New_Max_HP = (1.0 + HP%) × (Base_HP + Flat_HP) и сохраняет точный процент текущего здоровья: Current_HP = New_Max_HP × Ratio. При смене вещей доля здоровья не теряется.

	3. Аппаратные константы сущностей из конструктора (FUN_142f97cb0)
________________
В конструкторе базовой боевой сущности в C++ декомпиляторе зафиксированы аппаратные float-константы (PTR_FUN_147753ba0):
   * +0x158 (puVar1 + 0x2b) = 0x44960000 → 1200.0f — базовая защита сущности / делитель кривой брони (K).
   * +0x15c = 0x457a0000 → 4000.0f — базовый порог суперармора (Super Armor).
   * +0x160 (puVar1 + 0x2c) = 0x45fa0000 → 8000.0f — базовое здоровье (Base HP).
   * +0x164 = 0x41000000 → 8.0f — коэффициент регенерации / таймер восстановления.

	5. Точные формулы периодического урона (DoT) из GameBuffData.xml
________________
В строках ID="6104"–"6107" зашита точная структура тиков: ATTACKER#3#0.5#0.75#1
DoT_Tick = Total_ATK × TickMultiplier(Стек) × [1200 / (DEFeff + 1200)]
   * 1 стак: каждый такт наносит 50% ATK (0.50)
   * 2 стака: каждый такт наносит 75% ATK (0.75) (прирост +25%)
   * 3 стака: каждый такт наносит 100% ATK (1.00) (прирост +25%, максимальный лимит)
   * Урон мобов по игроку (ID 6204–6207): срезан ровно в 2 раза (1 стак = 25% ATK, 2 стака = 35% ATK, 3 стака = 50% ATK).
6. Стихийные синергии и элементальные реакции
________________
   * Огонь по Яду: FIRE#0.5 → +50% чистого урона огнем (×1.5) при ударе огненным навыком по отравленной цели.
   * Шок по Воде (Мокрый): SHOCK#1.0 → +100% чистого урона (удвоение ×2.0) при ударе молнией по намокшей цели (сопротивление огню при этом вырастает на -80%).
   * Шок по Холоду / Заморозке: SHOCK#0.5 → +50% чистого урона электро (×1.5).
   * Яд по Шоку: POISON#0.5 → +50% чистого урона ядом (×1.5).
   * Реакция контроля (AddPer: 2.0): Любой босс в состоянии нокдауна (DOWN), стана (STUN) или подброса (AIR) накапливает все стихии со скоростью ×2.0 (в 2 раза быстрее).
7. Скрытая системная прибавка крита от разницы уровней (BattleAdjustData.xml)
________________
При атаке цели, уступающей по уровню персонажу, движок автоматически начисляет скрытый бонус к шансу крита сверх характеристик экипировки (Critical_Adjust / 100):
   * +1 уровень: +0.10%
   * +5 уровней: +1.25%
   * +10 уровней: +5.00%
   * +15 уровней: +12.50%
   * +20 уровней: +20.00% чистого шанса крита
   * При атаке цели выше уровнем штрафа на шанс крита нет (Critical_Adjust = 0).
8. Срезы брони персонажей (GameBuffData.xml)
________________
   * Кастела (Актив 2, ID 10302, 1066, 1183): Defence_Per#-0.2 → -20% DEF цели.
   * Вероника (3-е пробуждение, ID 11931): Defence_Per#-0.2 → -20% DEF цели в дымовой завесе. Маунт: -5% постоянный дебафф, -15% тяжелая атака.
   * Алекс (Парирование, ID 120010–120019): скалируется от -10% (1 ур.) до -20% DEF (10 ур.).
   * Виола (Граб/Сигнал, ID 131020–131029): Defence_Per#-0.1 → -10% DEF цели.

	10. Итоговый приоритет характеристик (Stat Priority Meta)
________________
   1. S-Тир (Абсолютный приоритет):
   * Игнорирование защиты % (DEF Ignore %): Срезает броню до применения формулы насыщения K = 1200, давая мультипликативный прирост 7–15% реального урона. Сет на DEF Ignore после сигнатурных способностей безальтернативен.
   * Шанс крита (Crit Rate) и Крит. урон (Crit DMG): Строгий линейный умножитель урона.
   * Сила атаки % (ATK %): Перемножается со всем базовым и плоским пулом атаки.
   2. A-Тир:
   * Чистая атака (Flat ATK): Увеличивает плоскую базу, на которую затем умножаются все бонусы ATK %.
   3. F-Тир (Неэффективные параметры):
   * Доп. атака от негативных эффектов (Flat): Условная плоская прибавка (+125 ATK), дающая всего +1.3% реального урона на 70 уровне.
   * Плоское пробитие брони (Flat Pen = 75): Из-за делителя K = 1200 дает прирост менее 2% по эндгейм-целям.
