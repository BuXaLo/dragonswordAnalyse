\## 2. Что известно о параметрах комбо



`PCComboData.xml` хранит не только название действия, но и внутренние параметры:



| Поле | Что означает на уровне данных |

|---|---|

| `Index` | Идентификатор варианта действия внутри набора комбо |

| `GroupIndex` | Группа действия: обычная атака, активный навык, сигнал и т. п. |

| `SubGroupIndex` | Подгруппа или вариант действия |

| `ActionBuffList` | Список связанных action/buff ID |

| `OpenCondition` | Условие доступности варианта |

| `CoolTime`, `CoolTimeShare` | Перезарядка и связь перезарядок |

| `TargetCondition`, `ActiveCondition` | Условия применения/срабатывания |

| `AttackWeight` | Внутренний параметр атаки; не подтверждённый процент от ATK |

| `HitFury`, `HitAggro` | Параметры ярости/агрессии в системе игры |

| `SuperArmorBreak` | Параметр воздействия на суперброню |

\## 3. Прокачка и улучшения



В `PCSkillGrowthData.xml` у каждого навыка могут быть отдельные записи по уровням. Важные поля:



\- `SlotLevel` — уровень улучшения;

\- `NeedItemID1..4`, `NeedItemCount1..4` — необходимые материалы и их количество;

\- `Gold` — стоимость улучшения;

\- `AscendValue` — значение, связанное с этапом развития;

\- `SkillDesc\_2..4` — дополнительные описания;

\- `MasterSkillCondition` — условие мастер-навыка;

\- `ComboChangeID` — связь с изменениями комбо.



Чтобы построить полную таблицу стоимости, нужно собрать все строки с `CharacterID=10015` и сгруппировать по навыку и уровню. Одна строка не описывает всю прокачку.



\## 4. Что нужно для полного анализа боевой механики



1\. `PCComboLevelData.xml` — уровневые параметры комбо и проверка ключей связи.

2\. `PCActionDamageData.xml` — отдельные события попаданий, `AttackKey`, `ActionIndex`, `ComboIndex`, `DamageWeight`.

3\. `PCGeneralActionSetData.xml` — переходы между действиями и условия продолжения цепочек.

4\. `SkillComboConditionCheckData.xml` — расшифровка числовых условий.

5\. `SkillData.xml` и `GameBuffData.xml` — эффекты, длительность и правила наложения состояний.

6\. `PCComboChangeData.xml` — изменения комбо при развитии персонажа.



\## 5. Статус достоверности



\*\*Подтверждено:\*\* названия семи основных категорий, ID названий и описаний, описание контратаки, базовая запись атаки в прыжке и параметры двух пассивных атак.



\*\*Требует дальнейшей проверки:\*\* полный набор веток сигналов, все изменения после трансцендентности, точное число попаданий, коэффициенты урона от ATK, длительность эффектов и полная стоимость каждого уровня.



Не следует выводить точные проценты урона только из `AttackWeight` или считать `ActionBuffList` доказательством конкретного эффекта без соединения с таблицами действий и баффов.
