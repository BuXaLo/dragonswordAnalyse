## Что подтверждают данные

- У активного навыка 2 есть отдельная запись контратаки (`Index = 402`); описание локализации прямо связывает успешную контратаку с таймингом активации в момент атаки противника.
- Сигнал B разделён на условия: `TargetCondition = 9702` для воздушной реакции и `TargetCondition = 9704` для реакции на кровотечение. Эти варианты имеют общие базовые значения в `PCComboData`, но запускаются в разных ситуациях.
- Для сигнала A используются отдельные варианты с разным количеством зарядов. Не следует приписывать всем вариантам один набор значений без проверки их собственных строк.
- `ActionBuffList` у сигнала A (вариант 1) содержит `1067#11553`; у вариантов сигнала B встречается `11561`. ID баффа не доказывает величину эффекта без анализа записи в `GameBuffData`.

## Ограничения интерпретации

1. `AttackWeight` и `DamageWeight` нельзя напрямую читать как `% АТК`.
2. Ударные события нужно считать по `PCActionDamageData` с учётом `ActionIndex`, `AnimationName`, `ComboIndex`, `AttackKey` и `HitGroupIndex`.
3. `PCComboLevelData.ComboID` нельзя соединять с `PCComboData.ID` простым совпадением чисел: сначала требуется проверить составной ключ.
